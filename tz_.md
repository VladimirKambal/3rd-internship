# Практическая работа: передача по значению, ссылки и указатели в C++

## Часть 1. Передача по значению

### Задача

Реализовать функцию `swap_titles_by_value()`, которая пытается поменять местами названия двух книг, переданных **по значению**.

> **Примечание:** в условии была опечатка `swap_titles_by_balue`. Правильное название функции — `swap_titles_by_value`.

### 1. Добавьте функцию в `book.h`

```cpp
void swap_titles_by_value(Book b1, Book b2);
```

### 2. Реализуйте функцию в `book.cpp`

Функция должна менять местами названия двух переданных книг.

### 3. Измените `main.cpp`

Создайте два объекта книги, примените к ним функцию обмена названий.

Добавьте вывод названий обеих книг **до и после** применения функции.

### 4. Результат

Запустите программу.

**Что произошло? Почему названия не поменялись?**

При передаче объектов по значению функция получает их **копии**. Изменения происходят только с копиями `b1` и `b2`, а исходные объекты в `main()` остаются без изменений.
