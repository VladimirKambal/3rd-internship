# Практическая работа: передача по значению, ссылки и указатели в C++

## Часть 1. Передача по значению

Функция `swap_titles_by_value(Book b1, Book b2)` получает **копии** объектов. Обмен названий происходит только в локальных копиях, поэтому названия исходных книг в `main()` не меняются.

## Часть 2. Передача по ссылке

Функция `swap_titles_by_reference(Book& b1, Book& b2)` получает ссылки на исходные объекты, поэтому изменения сохраняются после выхода из функции.

- **Что такое ссылка (`T&`)?** Альтернативное имя уже существующего объекта. Обращение через ссылку работает с тем же объектом.
- **Можно ли объявить ссылку без инициализации?** Нет. `Book& ref;` не скомпилируется: ссылку необходимо сразу привязать к существующему объекту.
- **Можно ли перенаправить ссылку на другую переменную?** Нет. После инициализации ссылка остаётся привязана к тому же объекту. Присваивание через ссылку изменяет объект, а не саму привязку.

## Часть 3. Const-ссылки

`bool is_older(const Book& b1, const Book& b2)` сравнивает годы издания, не копируя книги и не позволяя изменять их через параметры.

- **Почему `const Book&`, а не `Book&`?** Функция только читает книги. `const` явно запрещает изменение через параметры, а ссылка избегает копирования объектов.
- **Что будет при попытке изменить `b1` или `b2`?** Вызов неконстантного метода или изменение поля через такую ссылку приведёт к ошибке компиляции.
- **Преимущество `const T&` перед `T` для больших объектов:** не создаётся копия объекта; при этом функция гарантирует, что не будет изменять его через эту ссылку.
- **Если передавать `Book` по значению:** сравнение будет работать, но параметры будут копиями и потребуются дополнительные затраты на копирование.
- **Если передавать `Book&` без `const`:** функция сможет изменять книгу. Константный объект нельзя передать в параметр `Book&`, поскольку это позволило бы обойти запрет на изменение константного объекта.

## Часть 4. Указатели

Функция `swap_titles_by_pointer(Book* b1, Book* b2)` меняет названия через указатели.

- **Что такое указатель (`T*`)?** Переменная, хранящая адрес объекта типа `T` (или специальное значение `nullptr`, означающее отсутствие объекта).
- **Что делает `&` при вызове функции?** В выражении `&bookA` оператор взятия адреса получает адрес объекта `bookA`.
- **Что делает `->`?** Оператор `b1->getTitle()` обращается к члену объекта, на который указывает `b1`; это сокращённая запись `(*b1).getTitle()`.
- **Может ли указатель быть `nullptr`?** Да. Разыменовывать `nullptr` нельзя: это приводит к неопределённому поведению. Функция обмена проверяет оба указателя и ничего не делает, если один из них равен `nullptr`.

## Часть 5. Проверка доступности

`bool is_book_available(const Book* book)` возвращает состояние доступности книги. Если передан `nullptr`, функция возвращает `false`, не пытаясь обращаться к несуществующему объекту.

В `main()` функция проверяется с адресом обычной книги, после выдачи книги и с `nullptr`.
